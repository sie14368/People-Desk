# PeopleDesk

PeopleDesk is a simple Employee Management System built using Spring Boot and MySQL. It allows users to perform basic CRUD (Create, Read, Update, Delete) operations on employee records through a simple web interface.

## Features

- Add new employees
- View all employees
- Update employee details
- Delete employees

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Maven
- Git & GitHub

## API Endpoints

| Method | Endpoint |
|--------|----------|
| GET | /employees |
| GET | /employees/{id} |
| POST | /employees |
| PUT | /employees/{id} |
| DELETE | /employees/{id} |
